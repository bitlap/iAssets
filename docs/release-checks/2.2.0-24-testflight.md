## 本轮内测待测与限制

- 从旧版升级并核对资产数据、备份恢复、自动转存默认关闭。
- 真机跨到期日、回前台和重启；错过多期补算后再次刷新不能重复续存；开关、期限、利率修改后核对本金与下一到期日。
- 自动转存按现有月数估算、原利率和期限计算；未运行期间在下次打开补算，不向银行发起交易。核对银行实际金额、计息天数及逐期舍入。
- iCloud 多设备同步与冲突、断网/保存失败、删除与更新失败恢复，以及小组件金额和语言独立验收。
- 真机购买/恢复和生产老用户凭据独立验收；TestFlight 沙盒不能证明生产环境老用户身份。
- 全语言译文未完成母语审校；Filipino/波斯语在平台无独立条目，按平台回退；完整映射与拒绝响应已保存，不计作后台翻译通过。
