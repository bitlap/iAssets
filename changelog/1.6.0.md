# 1.6.0

## 中文

### 新增
- **数字币资产**：新增数字币页面，暂时仅支持币安。使用 API 只读同步现货余额、U 本位和币本位合约权益及持仓，展示数量、参考价格、估值与合约未实现盈亏；不提供交易、转账或资产编辑。
- **带单账户**：支持普通账户，以及单独连接的现货带单和合约带单账户。跟单组合暂无可用的只读资产接口，本版不支持添加。
- **统一总资产**：数字币页面新增总资产卡片，按合约、现货、带单展示分类金额；数字币估值同时计入资产页面的总资产和资产分布。

### 优化
- **连接验证**：添加前测试真实账户与 API 权限，阻止相同凭证或重复账户接入。优先使用只读 API；含交易权限时提示风险，提现或转账权限未关闭、权限无法核验或测试失败时不能添加。
- **刷新与安全**：前台每 5 分钟自动刷新，也可下拉立即刷新。凭证仅存本机 Keychain，数字币资产数据仅在当前会话内存中展示，不写入本机文件或 iCloud。
- **界面与语言**：沿用现有卡片、货币选择和添加表单样式，适配深浅主题及红涨绿跌偏好；范围与注意事项仅在添加时显示。资产页总资产右侧的问号可查看资产分布，货币选择位于卡片最右侧。

## 繁體中文

### 新增
- **數字幣資產**：新增數字幣頁面，目前僅支援幣安。使用 API 唯讀同步現貨餘額、U 本位和幣本位合約權益及持倉，顯示數量、參考價格、估值與合約未實現盈虧；不提供交易、轉帳或資產編輯。
- **帶單帳戶**：支援一般帳戶，以及獨立連接的現貨帶單和合約帶單帳戶。跟單組合目前沒有可用的唯讀資產介面，本版不支援新增。
- **統一總資產**：數字幣頁面新增總資產卡片，依合約、現貨、帶單顯示分類金額；數字幣估值亦計入資產頁面的總資產和資產分布。

### 優化
- **連接驗證**：新增前測試實際帳戶與 API 權限，阻止相同憑證或重複帳戶接入。建議使用唯讀 API；包含交易權限時提示風險，提款或轉帳權限未關閉、權限無法驗證或測試失敗時不能新增。
- **重新整理與安全**：前景每 5 分鐘自動重新整理，也可下拉立即重新整理。憑證僅儲存於本機 Keychain，數字幣資產資料僅在目前工作階段的記憶體中顯示，不寫入本機檔案或 iCloud。
- **介面與語言**：沿用現有卡片、幣別選擇與新增表單樣式，支援深淺主題及漲跌顏色偏好；涵蓋範圍與注意事項僅在新增時顯示。資產頁總資產右側的問號可查看資產分布，幣別選擇位於卡片最右側。

## English

### Added
- **Crypto assets**: A new crypto page with read-only Binance sync for spot balances, USDⓈ-M and COIN-M futures equity and positions. View quantities, reference prices, estimated values, and unrealized futures P&L. Trading, transfers, and asset editing are unavailable.
- **Lead trader accounts**: Connect regular accounts or separate spot and futures lead trader accounts. Copy trader portfolios cannot be added because a suitable read-only asset API is unavailable.
- **Combined total assets**: The crypto summary shows futures, spot, and lead trader values. Estimated crypto value also contributes to the Assets page total and allocation breakdown.

### Improved
- **Connection checks**: Test the actual account and API permissions before adding it; reject duplicate credentials and accounts. Read-only API keys are recommended. Trading permission triggers a risk warning; withdrawal or transfer permission, unverifiable permissions, and failed tests prevent adding a connection.
- **Refresh and security**: Refresh automatically every 5 minutes while the app is in the foreground, or pull to refresh. Credentials stay in the device Keychain; crypto asset data stays in memory for the current session and is not written to local files or iCloud.
- **Interface and languages**: Reuse the existing summary card, currency picker, and account form styles across light and dark themes and both gain/loss color preferences. Scope and cautions appear when adding an account. On the Assets page, the help icon beside Total Assets opens the allocation breakdown, and the currency picker sits at the far right.
