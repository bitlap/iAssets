# 1.6.0

- 新增“数字币”页面，暂时仅支持币安账户只读同步，展示现货余额、参考估值、合约权益及仓位，不提供资产编辑、成本录入或交易操作。
- 支持普通账户，以及使用项目专用 API 单独连接的现货带单和合约带单账户；跟单组合暂无公开资产接口，暂不支持添加。
- 添加连接前验证账户、读取权限及所需接口，防止同一账户或钱包重复计入。建议使用只读 API，含交易权限时提示风险并允许测试成功后添加；提现、转账权限或无法核验的权限不予接入。
- 数字币总资产卡片按带单、合约、现货三列展示分类金额，三列数值不显示货币符号；数字币估值计入资产页总资产及资产分布。
- 页面标题下显示最近成功更新时间，沿用股票页面格式。前台每 5 分钟自动刷新，下拉立即查询；查询失败保留当前会话上次成功结果并提示。
- 凭证与连接配置仅存本机 Keychain，不参与 iCloud 或备份。资产数据仅保留在当前会话内存中，不保存到本机；启动时清理旧快照文件。
- 精简连接后的展示，账户标题仅显示自定义名称，范围及注意事项仅在添加时提示；通过底部加号添加账户。
- 共用股票及资产页面的汇总卡片、货币选择、表单弹窗、输入框、操作按钮、移除确认及空状态组件。带单、合约、现货使用紫、蓝、青绿分类色，支持深浅主题和即时切换红涨绿跌偏好。
- 支持简体中文、繁体中文和英文，账户名称、持仓字段、凭证字段、风险及错误提示均接入本地化。

具体账户覆盖范围和 API 限制见 [只读同步说明](../docs/crypto-sync.md)。
