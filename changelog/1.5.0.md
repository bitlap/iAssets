# 1.5.0

## 中文

### 新增
- **主题设置**：跟随系统 / 浅色 / 深色
- **红涨绿跌**：涨跌颜色可切换
- **自定义股票**：手动录入名称、持仓、价格与币种，支持选择图片

## 繁體中文

### 新增
- **主題設定**：跟隨系統 / 淺色 / 深色
- **紅漲綠跌**：漲跌顏色可切換
- **自訂股票**：手動輸入名稱、持倉、價格與幣種，支援選擇圖片

## English

### Added
- **Theme setting**: System / Light / Dark
- **Red up, green down**: toggle rise/fall colors
- **Custom stock**: manually add name, shares, price and currency, with optional image
