# 1.2.0

### UI 视觉统一
- **配色统一**：底部 tab 图标不分选中/未选始终有颜色（股票蓝 `#5B9CF6` / 资产橙 `#FF9F0A`），icon 在上文字在下
- **字体层级**：第一行左右统一 `fontSize: 13`，第二行左右统一 `fontSize: 12`，所有计算公式/时间/日期统一 `fontSize: 11, color: Colors.grey[500]`
- **分割线统一**：所有 Divider 统一 `thickness: 0.5, color: Color(0xFF1C1C1E)`
- **按钮风格**：悬浮按钮和齿轮改为白底黑图标；记录 button icon 蓝色 `#5B9CF6`，更多 button icon 橙色 `#FF9F0A`
- **分类标题**：字号从 16 改为 14，与资产内容标题一致
- **Switch**：开启态改为蓝色 `#5B9CF6` 轨道和拇指

### 样式常量系统
- **AppColors**：移除所有 inline `Color(0x...)` 硬编码，抽取为 15+ 命名常量（`surface` / `border` / `surfaceElevated` / `textSecondary` / `accent` / `warning` / `danger` / `success` / `cyan` / `purple` / `blueDark` / `blueAccent` / `greenAccent` / `redAccent` / `lightBlue` / `separator` / `tertiaryBg`）
- **TextStyles**：新增 9 个通用文本样式常量（`dialogTitle` / `sectionTitle` / `subtitle` / `bodyMedium` / `bodyRegular` / `body13` / `smallBold` 等），widgets/ 目录零内联 `TextStyle` 硬编码
- **公共组件**：抽取 `DashedDivider` / `FilterPill` / `StatMetricCard` / `YieldTile` / `MarketBadge` / `CurrencyBadge` 可复用 widget
- **全量替换**：settings_page、stock/*、asset/*、common/* 共 27 个文件全部使用共享常量，全局改色只需改 `app_colors.dart`

### 底部导航栏改造
- **统一容器**：股票 / 资产 / 添加 三个 tab 在同一个圆角容器中，icon 在上文字在下的统一布局
- **加号按钮**：固定在底部「资产」tab 右侧，统一 `padding: horizontal: 24, vertical: 8` + `borderRadius: 20`
- **移除冗余**：去掉页面内的 DraggableFab 浮动按钮和 SectionTitle 的 onAdd，统一由底部 + 号调度

### 股票页面优化
- **盈亏列**：通过 `Spacer()` 推到最右侧，header 右 padding 改为 26 匹配卡片边缘
- **卡片主行**：改为 `Expanded(flex:2)+Expanded(flex:2)+Spacer+profit` 与表头对齐
- **持仓列**：`Alignment.center` → `Alignment.centerLeft` 解决 iPad 宽屏偏移
- **股息/操作记录**：股息记录第三行改为 Row（左侧操作时间 + 右侧派息日期）；操作记录第三行改为 Row（左侧更新时间 + 右侧创建时间），Flexible + ellipsis 防溢出
- **计算公式**：去掉「股」「$」「每股」单位符号，纯数字显示
- **弹窗**：股票更多弹窗选项间加 Divider
- **展开详情**：改为每行 2 项，标题和值同一行（`总成本: 1,234`），左列左对齐、右列右对齐，`FittedBox` 防溢出
- **表头股票数**：「股票」文字右侧显示括号股票数量（如 `股票(5)`）
- **最近更新**：subtitle 从「共 X 只 · 实时更新」改为「最近更新：2026-07-26 14:30:00」，刷新完成时即时更新时间戳

### 资产页面优化
- **icon/颜色**：理财/基金 icon `#2C2C2E` → `#5B9CF6`；名称文字 `#8E8E93` → `Colors.white`
- **弹窗**：资产添加弹窗选项间加 Divider

### 新增资产类型
- **活期存款**：新增 `AssetType.current` 类型，`CurrentAccount` 模型（同 CashAccount 结构），icon `Icons.account_balance` / `#5AC8FA`
- **公积金**：新增 `AssetType.providentFund` 类型，`ProvidentFundAccount` 模型（同 CashAccount 结构），icon `Icons.home_work` / `#AF52DE`
- **通用弹窗**：`_BalanceDialog` 通用弹窗供现金/活期/公积金复用
- **数据驱动**：`showAddAssetSheet` 改为数据驱动 `_assetOptions` 列表，新增类型只需加一项
- **文案更新**：现金提示从「例：活期账户、钱包」改为「例：钱包、储蓄卡」

### 数字格式化调整
- **formatCompact**：`≥ 1亿` → `X.XX亿`，`≥ 100万` → `X.XX万`，`< 100万` → 显示完整数字

### 刷新逻辑重构
- **统一入口**：`_refreshAll()` 统一负责先加载 iCloud 再获取行情
- **清理**：删除 `_isLoading`、加载覆盖层、冗余 `_fetchExchangeRatesWithoutRebuild`

### 修复
- **汇率持久化**：成功请求汇率后写入本地文件；`ExchangeRateService.effectiveRates` 三级兜底（实时汇率 → 同步读文件 → 默认值），冷启动或 API 失败时自动从文件恢复，不再依赖手动 `updateRates`
- **CurrencyUtil**：`CurrencyHelper` 更名为 `CurrencyUtil`，仅保留格式化/符号/换算方法；`supportedCurrencies`、`exchangeRates`、`getExchangeRate` 迁移至 `ExchangeRateService`
- 修复资产列表名称颜色显示异常
- 修复理财/基金 icon 颜色显示错误
- 修复后台切回前台时 `recordProfitIfNeeded` 使用未刷新行情写入陈旧快照（`_recordProfitOnPaused` 先刷新行情再记录）
- 修复启动时展示旧股价：`_refreshAll` 和 `_recordProfitOnPaused` 获取行情后立即 `saveStocks`，确保磁盘 `currentPrice` 保持最新
- **更新 AppIcon**：使用新版 1024 源图重新生成所有尺寸
- **边框一致性**：`SettingsExpansionCard` 边框宽度默认 `1.0` → `0.5`，与全局 Divider 统一
- **按钮间距修复**：SectionTitle 多个按钮之间的间隙不再依赖 `onAdd` 回调，股息/设置按钮间始终保留 8px

### A股支持
- **搜索**：东方财富 suggest API 的 `SecurityTypeName`（沪A/深A/美股/港股）直接作为 market，`QuoteID` 作为 secid，去掉 `MktNum` 手动映射
- **行情**：腾讯接口 `sh`/`sz` 前缀；东方财富改用 `f12`（股票代码）匹配响应结果，不再依赖数组顺序
- **货币**：`currencyForMarket("A股")` → `CNY`
- **筛选**：搜索弹窗和持仓页筛选新增「A股」选项，橙色 `#FF9500`；`A股` 模糊匹配 `沪A`/`深A`
- **secid 回退**：`_secidForMarket` 统一通过 `MarketUtil` 处理

### MarketUtil
- **提取**：所有市场相关工具（`marketColor`/`marketIcon`/`tencentPrefix`/`secidForMarket`/`matchesFilter`、市场标识常量、交易所代号、secid 前缀）从 `StockConfig` 迁移至 `lib/utils/market_util.dart`

### 重构
- **AssetDataManager**：新增 `lib/services/asset_data_manager.dart`，封装资产数据加载/持久化/平铺构建，`assets_page.dart` 简化为状态管理，移除对 `IcloudStorage` / `SettingsService` 的直接依赖
- **收益曲线**：`profit_chart.dart` 改用 `StockDataManager.loadDailyProfitHistory/loadIntradayProfitHistory`，移除 `IcloudStorage` 导入
