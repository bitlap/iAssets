# 2.2.0

## 简体中文

- 调整资产拖拽排序后的保存顺序，并更新排序接口，验证上下移动后分类顺序及资产数据保持正确。
- 修复 iPad 底部弹窗宽度受限的问题，支持横竖屏和分屏自适应；完善小组件语言声明、组件选择页说明及长状态文案布局。
- 修复多语言数字回填导致交易、资产或股息编辑无法保存、手续费被记为零的问题；防止带千位分隔符的粘贴改变金额数量级。
- 修复多语言记录标题截断及切换语言后不更新的问题，兼容旧版记录；改善展开设置、资产总览、反馈及股票搜索的窄屏布局，并校正关键金融术语。
- 新增 30 种语言，现共支持 33 种界面语言；可手动选择或跟随系统，iOS 权限说明及桌面、锁屏组件同步支持。
- 新增语言使用本地日期和数字格式；支持阿拉伯语、波斯语和希伯来语的从右向左布局，优化长文案在窄屏上的显示。
- 数字输入支持小数逗号，以及阿拉伯、波斯、印地、孟加拉、泰文和全角数字。
- 意见反馈中新增开源说明及 GitHub 仓库链接，方便提交建议或报告问题。

## 繁體中文

- 調整資產拖曳排序後的儲存順序，並更新排序介面，驗證上下移動後分類順序及資產資料保持正確。
- 修復 iPad 底部彈窗寬度受限的問題，支援橫直螢幕及分割畫面自適應；完善小工具語言宣告、選擇頁說明及較長狀態文字的版面。
- 修復多語言數字回填導致交易、資產或股息編輯無法儲存、手續費被記為零的問題；避免帶千位分隔符的貼上內容改變金額數量級。
- 修復多語言記錄標題截斷及切換語言後未更新的問題，兼容舊版記錄；改善展開設定、資產總覽、回饋及股票搜尋的窄螢幕版面，並校正關鍵金融術語。
- 新增 30 種語言，現共支援 33 種介面語言；可手動選擇或跟隨系統，iOS 權限說明及桌面、鎖定畫面小工具同步支援。
- 新增語言使用當地日期及數字格式；支援阿拉伯語、波斯語和希伯來語由右至左的版面，改善長文字在窄螢幕上的顯示。
- 數字輸入支援小數逗號，以及阿拉伯、波斯、印地、孟加拉、泰文和全形數字。
- 意見回饋中新增開源說明及 GitHub 儲存庫連結，方便提交建議或回報問題。

## English

- Updated asset reordering and its save sequence, with regression checks for category order and asset data after moves in either direction.
- Fixed bottom sheets being too narrow on iPad, including rotation and Split View. Completed widget language declarations, matched gallery descriptions to the app language, and prevented long status text from overlapping update times.
- Fixed localized form values preventing trade, asset and dividend edits from saving or causing fees to be recorded as zero; grouped number pastes no longer silently change an amount’s scale.
- Fixed truncated trade titles and language switching for legacy records. Improved narrow-screen layouts for expanded settings, asset summaries, feedback and stock search, and corrected core financial terminology.
- Added 30 languages, bringing the total to 33. Choose a language or follow the system; iOS permission descriptions and Home Screen and Lock Screen widgets support the same languages.
- Added local date and number formats for the new languages, right-to-left layouts for Arabic, Persian and Hebrew, and improved long-text layouts on narrow screens.
- Numeric input now accepts decimal commas, Arabic, Persian, Devanagari, Bengali, Thai and full-width digits.
- Added an open-source notice and GitHub repository link to Feedback for suggestions and issue reports.
