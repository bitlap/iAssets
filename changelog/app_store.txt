iAssets — 看清资产，轻松记录

在一个 App 中查看股票、数字币和其他资产，了解总额、分布与收益。

【主要功能】
• 追踪多个市场的股票持仓，记录买卖与股息，查看市值和收益
• 通过币安 API 只读查看现货、合约和带单资产
• 管理现金、存款、理财及自定义资产分类，汇总多币种资产
• 使用桌面和锁屏组件，快速查看资产总览

【隐私与体验】
• 支持 Face ID / Touch ID 应用锁和一键隐藏金额
• 股票、手动资产和设置支持 iCloud 同步；数字币凭据仅保存在本机
• 支持包括简体中文、繁体中文、英文在内的 33 种语言，以及深浅主题
• 免费使用基础功能，Pro 提供订阅或一次性买断
