# 2.1.0

## 简体中文

- 新增可选的 Face ID / Touch ID 应用锁：冷启动及返回应用时验证身份，必要时可使用设备密码恢复访问。
- 新增一键隐藏金额，遮挡资产、持仓和收益中的金额；可在首页或设置中切换。
- 切换到后台时，应用预览显示隐私遮罩，避免敏感信息出现在应用切换器中。
- 隐私开关仅保存在当前设备，不参与应用内 iCloud 同步或导出备份。默认关闭，升级后由用户自行开启。
- 新增桌面小号、中号、大号及锁屏行内、矩形资产组件，显示总资产、分类金额和更新时间；隐藏金额或启用应用锁时，组件同步隐藏金额。
- iOS 后台股票收益任务运行时，也会同步数字币并更新组件摘要；实际运行时间由系统决定，后台查询失败时保留上一份组件金额。

## 繁體中文

- 新增可選的 Face ID / Touch ID App 鎖定：冷啟動及返回 App 時驗證身分，必要時可使用裝置密碼恢復存取。
- 新增一鍵隱藏金額，遮蔽資產、持倉和收益中的金額；可在首頁或設定中切換。
- 切換到背景時，App 預覽顯示隱私遮罩，避免敏感資訊出現在 App 切換器中。
- 隱私開關僅儲存在目前裝置，不參與 App 內 iCloud 同步或匯出備份。預設關閉，升級後由用戶自行啟用。
- 新增桌面小型、中型、大型及鎖定畫面行內、矩形資產小工具，顯示總資產、分類金額和更新時間；隱藏金額或啟用 App 鎖定時，小工具亦會隱藏金額。
- iOS 背景股票收益任務執行時，也會同步數字幣並更新小工具摘要；實際執行時間由系統決定，背景查詢失敗時保留上一份小工具金額。

## English

- Added an optional Face ID / Touch ID app lock. Authenticate on launch and when returning to the app; your device passcode can restore access when needed.
- Added one-tap amount hiding for assets, holdings and earnings. Toggle it from the home screen or Settings.
- A privacy cover hides the app preview in the app switcher when you leave the app.
- Privacy preferences stay on the current device and are excluded from in-app iCloud sync and exported backups. They are off by default and can be enabled after updating.
- Added small, medium and large Home Screen widgets, plus inline and rectangular Lock Screen widgets, showing total assets, category values and update time. Widgets hide amounts when amount hiding or app lock is enabled.
- When iOS runs the background stock earnings task, it also syncs crypto and updates the widget summary. iOS determines the actual timing; failed background queries retain the previous widget amounts.
