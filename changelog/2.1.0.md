# 2.1.0

## 简体中文

- 新增 Face ID / Touch ID 应用锁、一键隐藏金额；开启应用锁时保护后台预览。
- 新增桌面与锁屏资产组件，快速查看资产总览。
- 数字币与资产组件支持后台刷新。

## 繁體中文

- 新增 Face ID / Touch ID App 鎖定、一鍵隱藏金額；啟用 App 鎖定時保護背景預覽。
- 新增桌面與鎖定畫面資產小工具，快速查看資產總覽。
- 數字幣與資產小工具支援背景重新整理。

## English

- Added Face ID / Touch ID app lock and one-tap amount hiding; app lock also protects the app-switcher preview.
- Added Home Screen and Lock Screen widgets for an at-a-glance asset overview.
- Crypto and asset widgets support background refresh.
