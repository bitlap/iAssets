# 1.3.0

### 修复

- **切换 tab 时金额闪烁为 0**：股票总市值缓存在父组件中，`_onTabChanged` 时预先同步，避免过渡帧中股票页 state 不可用导致的闪零
- **toast 文字双黄线**：恢复 `decoration: TextDecoration.none` 显式声明；修复 `_openDialog` 中 `use_build_context_synchronously` 警告（在 `await` 后补全 `mounted` 检查）
- 修复场外基金价格（净值）的单位问题，资产页面中的`理财/基金`类别改为`理财`
- 修复在资产页面切换币种时，股票资产金额不随币种变化的问题
