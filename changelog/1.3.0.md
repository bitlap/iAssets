# 1.3.0

### 新增
- **今日盈亏**：股票头部卡片新增「今日盈亏」金额 + 盈亏率展示（红涨绿跌），位于总资产右侧、货币切换旁边，上方文字、中间金额、下方盈亏比例
- **今日盈亏口径**：以美股市场（美东时间）每天 9:00 为日界线（覆盖美股开盘），基线 = 日界线时的总盈亏即昨收；盈亏率 = 今日盈亏 ÷ 昨收总资产
- **时区适配**：新增 `lib/utils/trading_day_util.dart`，日界线锚定美东时区（自动判断夏令时：3 月第二个周日 02:00 EST → 11 月第一个周日 02:00 EDT），无论设备本地时区在哪，都统一按美股交易时段划界
- **基线持久化**：`today_baseline.json` 记录基线，随收益快照同步 iCloud；后台任务跨日时自动更新基线
- **今日盈亏曲线**：盈亏曲线的「今日」视图改为展示相对基线（昨收）的当日盈亏，并按美东 9:00 日界筛选数据，与盈亏基线口径一致
- **计算公式**：设置页「计算公式」列表新增「今日盈亏」说明项

### UI 优化
- **盈亏曲线**：去掉「盈亏曲线」文字标题，仅保留展开图标；展开详细曲线时折叠小曲线
- **ProfitUtil 抽取**：新增 `lib/utils/profit_util.dart`，统一「红涨绿跌 + 零值灰显」的颜色/符号逻辑（`colorOf`/`signOf`/`amount`/`percent`），替换股票卡片盈亏列、涨跌幅、头部卡片总盈亏/今日盈亏/帮助弹窗中的冗余代码

### 修复
- **切换 tab 时金额闪烁为 0**：股票总市值缓存在父组件中，`_onTabChanged` 时预先同步，避免过渡帧中股票页 state 不可用导致的闪零
- **toast 文字双黄线**：恢复 `decoration: TextDecoration.none` 显式声明；修复 `_openDialog` 中 `use_build_context_synchronously` 警告（在 `await` 后补全 `mounted` 检查）
- 修复场外基金价格（净值）的单位问题，资产页面中的`理财/基金`类别改为`理财`
- 修复在资产页面切换币种时，股票资产金额不随币种变化的问题
